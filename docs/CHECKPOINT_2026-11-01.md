# Working two-player nightclub checkpoint

The user confirmed two Windows players in the same completed nightclub,
synchronized activity and virtually no noticeable lag. The checkpoint includes
native builder import/inspection/environment capabilities, procedural original
nightclub modules and effects, corrected avatar dance retargeting, hotbar slot 1,
separate opt-in development identities, private-network guest routing and local
host startup ownership confirmation.

Backend authentication tests, isolated native client/effects/dance checks and
script scanning supplement that live acceptance. Public internet hosting and
instrumented ten-player performance have not been validated. Minor avatar shirt
deformation is deferred. Music transport/beat synchronization is not implemented.

Machine credentials, private tester ZIPs, runtime receipts and local world-state
ledgers are excluded. The world itself remains in the local backend database;
Git preserves source/build recipes, not a database backup. Native engine changes
are preserved under tools/engine-patches; apply those before rebuilding.
The two preexisting locomotion edits, generated avatar import settings and local
configuration remain intentionally uncommitted.
